# tay is gay

瀏覽器裡的雙人單挑 FPS：地形可以打爛、每局重置、用錢買裝備、輸家有補償、搶分制。
純靜態網頁（Three.js + PeerJS），沒有建置步驟，也不需要自己的伺服器。圖片、模型、音效全部由程式產生，沒有任何素材檔。

線上版：https://jonathan94875434-design.github.io/rubble-duel/

> 要改這個專案的人（和他的 Claude）：先看最後一節「[交接](#交接給協作者和他的-claude)」。

## 怎麼玩

- 跟朋友玩：一人按「建立房間」→「複製邀請連結」傳給對方，對方打開後按「加入房間」。等朋友的時候可以按「熱身」先跟機器人打（無限重生），朋友一進來會自動回到大廳。
- 自己練：按「單人練習」，可以選對手難度（木樁／簡單／普通／困難）和地圖。
- 自己蓋地圖：主選單的「地圖編輯器」。存檔後會出現在地圖選單；「複製分享代碼」可以把地圖貼給朋友，對戰時房主選自製地圖也會自動傳給對方。
- 本機開發：Mac 雙擊 `start.command`、Windows 雙擊 `start.bat`，瀏覽器會打開 `http://localhost:8765/`。同一台電腦測雙人：網址加 `?local=1`，開兩個視窗。

預設按鍵（都可以在「設定 / 按鍵」裡改）：

| --- | --- |
| 移動、跳（按住連跳）、蹲 | WASD、空白鍵、C |
| 開火、瞄準 | 左鍵、右鍵或左 Shift |
| 主槍／副槍／刀、切回上一把 | 1 / 2 / 3、Q（滾輪也可以） |

## 規則

- **回合**：一局一條命，先拿到目標分數的人贏。每局地形重置。
- **經濟**：開場 $800，每局開打前買裝備（買了就花掉，商店每局重置）。第 1 局是手槍局。贏一局 +$2000，輸一局 +$3000，連敗每局再 +$500（上限 $4500）。
- **強化**：輸的人下一局可以三選一拿一個強化（房主可以在大廳改成不給）。
- **地圖**：廢墟廣場（黃昏）、三線街區（正午，有地下道）、貨櫃碼頭（陰天）、礦場（清晨，高地／谷底／隧道），加上自己做的。房主可指定、隨機或每局輪換。
- **身法**：急停、蹲跳、連跳；空中按方向鍵或轉視角就能轉彎，速度不會掉。跑步有腳步聲，瞄準走和蹲走沒有。拿刀跑最快。
- **穿牆**：子彈每穿過一格方塊會消耗穿透力（木板、鐵皮很薄；磚、水泥要步槍以上；鋼板幾乎只有狙擊槍穿得過一格），穿過去之後傷害打折。
- **刀**：每個人都有，砍到就一刀斃命（護甲擋不住）。左鍵快砍，瞄準鍵突刺（搆得比較遠、收刀慢）。
- **受傷方向**：被槍或刀打中時，準星外圍會有一段紅色弧線指向對手，轉頭時跟著轉。
- **燃燒瓶**：地上燒 7 秒，站在裡面一直扣血，會燒掉木頭；煙霧彈可以滅火。
- **小地圖**：對手只有在你看得到他、或他開槍時才會出現。
- **回合結束**：顯示傷害報告（雙方各打中幾發、多少血）；被擊倒的人會看到擊殺回放（點一下跳過）。

## Roguelike 模式

房主在大廳把「模式」改成 Roguelike（單人練習在選單勾「練習用 Roguelike 模式」）。

- **每局選一張異能卡**：開打前雙方各從 3 張裡選 1 張，整場累積。上一局輸的人有 4 張可以選，也比較容易抽到稀有、傳說（取代一般模式的輸家強化）。
- **被動**不限數量，拿了就一直有效；**主動技能**最多帶兩個，按技能鍵施放。兩格都滿了再拿新技能，要挑一個換掉。
- **先選卡、再買裝備**：自己選好之前看不到對手這一局拿了什麼；選完才公開，接著才買槍。對戰中記分板下面也看得到對手帶的所有異能。
- **重抽**：花 $400 換一批，每局最多 2 次。
- **主動技能**：瞬移、鉤索、噴射背包、鋼牆、腎上腺素、透視脈衝（普通）；光學迷彩、能量護罩、震地衝擊波（稀有）；時間凝結、軌道砲、黑洞（傳說）。
- **被動**：原本的 12 個強化，加上鷹眼、穿甲彈、雷達、無聲步、月球靴、投資客、軍火庫（普通）；扳機狂熱、玻璃大砲、重裝巨人、狂戰士、荊棘、冰凍彈、燃燒彈、爆裂彈、跳彈（稀有）；雙重射擊、不死鳥（傳說）。
- 互相剋的例子：迷彩怕雷達和透視脈衝；護罩擋子彈但擋不了爆炸和走進來的人；黑洞、時間凝結可以用瞬移／鉤索／噴射背包逃；不死鳥專剋一刀斃命。

## 架構

- `main.js` 主迴圈、輸入、畫面狀態機
- `world.js` 體素世界（破壞、區塊網格、射線、穿牆、碰撞）；`maps.js` 內建地圖與自製地圖的編碼／解碼；`editor.js` 地圖編輯器
- `player.js` 移動物理（固定 120Hz）；`combat.js` 開槍、刀、後座、拋射物、火焰
- `net.js` 連線（WebRTC／同機／電腦對手三種通道）；`voice.js` 語音（PeerJS 通話，點對點）
- `authority.js` 裁判，只在房主端執行：血量、回合、分數、金錢、強化、補給品、地圖輪換、熱身的重生
- `cards.js` Roguelike 的卡片表與抽卡；`skills.js` 主動技能（施放、冷卻、對雙方的效果、特效）
- `bot.js` 練習對手；`nav.js` 它用的 A* 尋路
- 畫面：`textures.js` 方塊材質、`light.js` 天光（室內變暗）、`env.js` 天空與天氣、`post.js` 光暈與調色、`skylit.js` 讓角色和碎屑也吃到天光、`fx.js` 粒子／彈孔／爆炸／煙／火／噴漆
- 模型：`gunmodel.js` 槍與投擲物、`viewmodel.js` 第一人稱的槍和手、`remote.js` 角色（對手、造型預覽、擊殺回放裡的自己）、`icons.js` 把槍拍成商店用的小圖
- `hud.js` 介面；`minimap.js` 小地圖；`replay.js` 擊殺回放；`stats.js` 戰績；`audio.js` 合成音效
- `dev/` 是開發時看模型、聽音效用的預覽頁，遊戲本身不會用到

連線模型：房主管回合、血量與金錢；命中由開槍方判定（打到就算）；
方塊傷害與爆炸雙向同步，每局開始兩邊各自重建同一張地圖。火焰的傷害由丟的人負責算。
技能跟子彈一樣是「施放的人說了算」：自己這邊先生效，再用 `sk` 訊息告訴對手；會改地形的走既有的爆炸訊息。
選卡、重抽、金錢，以及荊棘／不死鳥／灼燒這類跟血量有關的被動，都在裁判那邊算。

## 測試

```
cd tests && npm install
npm run features    # 身法物理、尋路（四張圖）、經濟、投擲物、改鍵
npm run practice    # 每把槍、補給品、電腦對手流程
npm run duel        # 雙人完整流程（同機通道）
npm run duel:peer   # 同上，走真的 WebRTC
npm run new         # 穿牆、刀、燃燒瓶、傷害報告、擊殺回放、戰績、噴漆、表情、小地圖、準星、地圖編輯器
npm run warm        # 熱身、陪練機器人讓位、自製地圖同步、噴漆／表情／火焰同步
npm run warm:peer   # 同上，走真的 WebRTC，另外測語音
npm run rogue       # Roguelike：選卡、重抽、換技能、每個主動技能、幾個被動、技能音效
npm run rogue:duel  # Roguelike 雙人同步：選卡公開的時機、技能效果與地形兩邊一致
npm run audio       # 每個音效離線算一遍，檢查音量、長度、左右聲道
```
需要先啟動本機伺服器（`start.command` 或 `start.bat`），電腦上要有 Node 和 Chrome。
Chrome 不在預設位置時用環境變數 `CHROME` 指定執行檔。要測線上版：`BASE=https://… npm run duel:peer`
（Windows PowerShell 的寫法是 `$env:BASE="https://…"; npm run duel:peer`）。
`node shot.mjs`、`node shot-play.mjs` 是截圖用的小工具（看畫面，不算測試）。

## 交接：給協作者和他的 Claude

這個 repo 現在有兩個人在改，也就是這個遊戲的兩個玩家：原作者（Mac，滑鼠是 Magic Mouse）和協作者（Windows，RTX 4080 桌機）。
這一節是寫給協作者那邊的 Claude 看的。先讀完這一節，再讀上面的「架構」和「想調整時改哪裡」，然後才動手。

### 現在的狀態（2026-11-21）

- 上面寫的功能都做完了，而且已經在線上：一般模式、Roguelike 模式、4 張地圖和地圖編輯器、熱身、擊殺回放、語音、造型。
- 沒有做到一半的工作，也沒有已知的 bug。「測試」那一節的每一套在 Mac 上都通過。
- 到目前為止只有原作者一個人對機器人玩過。兩個人真的連線對打還沒發生過。

### 接下來要做的事

照順序做。前四項都要真人玩過才有答案，Claude 的工作是把玩的人講的感覺變成修改。

1. **先讓 Windows 這邊能開發。** 雙擊 `start.bat` 開本機版，然後 `cd tests && npm install`，把「測試」那一節的每一套跑一遍。
   `start.bat` 和測試的 Windows 路徑都是在 Mac 上寫的，沒有在 Windows 上跑過；壞了就先修這個。
2. **兩個人從各自的家裡連線打一場。** 連線用 PeerJS 預設的公用伺服器，沒有自己的伺服器。要確認的事：連不連得上、語音（按住 K）、延遲感、打爛的地形兩邊是不是一樣。
   有問題先記下重現方式再修；`npm run duel:peer` 和 `npm run warm:peer` 是同一台電腦上走真 WebRTC 的版本，可以拿來對照。
3. **調 Roguelike 的平衡。** 42 張卡的數值全部是第一版，沒有人實際對打過。最可能出問題的是黑洞、軌道砲、時間凝結。
   打幾場，把「太強、太弱、太無聊」的卡記下來，再去改 `js/cards.js` 和 `js/skills.js`。
4. **看效能，聽音效。** 4080 上「高」畫質的幀數、Mac 在 Retina 解析度的幀數都沒有量過（畫質分級在 `js/post.js`）。
   音效全部是程式合成的，只做過離線量測，沒有人認真聽過；`dev/audio.html` 可以一個一個試聽。
5. **可做可不做**：練習機器人只會用 6 個技能（腎上腺素、時間凝結、震地衝擊波、軌道砲、能量護罩、光學迷彩），另外 6 個不會用。

除此之外沒有排定的功能。之後的工作就是兩個人玩過之後提出來的修改。

### 做事的規矩

- **push 到 `main` 大約 30 秒後就上線**（GitHub Pages），沒有測試環境，另一個人重新整理就會拿到。
  所以：動手前先 `git pull --rebase`；push 前跑跟改動有關的測試；一次提交一件事，訊息寫清楚改了什麼，因為另一個人是靠 `git log` 知道你做了什麼；不要 force push。
- **repo 是公開的。** 真名、信箱、金鑰都不要寫進檔案或 commit。commit 身分建議用 GitHub 提供的 noreply 信箱。
- **介面文字、註解、commit 訊息、這份 README 都用繁體中文。**
- **不要加框架、打包工具或素材檔。** 這是純靜態網頁，`vendor/` 裡只有 Three.js 和 PeerJS；圖片、模型、音效全部是程式產生的。要破例先問兩位玩家。
- **新功能要有測試**，加在 `tests/` 對應的那一套裡。改了規則或按鍵，README 上面幾節也要跟著改。
- **開放性的設計問題先問人**（新模式、大改玩法、要不要某個功能）。明確的要求（「把 X 改成 Y」）直接做。

### 已經定案的設計，不要改回去

這些都是原作者玩過之後指定的：

- 只做瀏覽器版，Mac 和 Windows 都要能玩。
- 不做炸彈模式。畫面走偏寫實。
- 左 Shift 也能瞄準，而且預設按鍵不能要求同時按滑鼠左右鍵，也不能只靠滾輪：Magic Mouse 做不到。
- 預設按鍵不要用 Ctrl（Windows 的 Ctrl+W 會關掉分頁）。
- 身法要簡單：跳起來可以轉方向而且速度不掉。不要做成靠技巧才能加速的旋轉跳。
- 商店每局重置，不沿用上一局買的東西，也不自動配裝。
- 輸的人要有補償（錢比較多；Roguelike 是多一張卡可以選）。第 1 局只能買手槍。
- 刀砍到就死。瞄具、鏡框、準星要細，不能擋視線。被打中時準星外圍要有指向敵人的紅色弧線。
- 遊戲顯示的名字是「tay is gay」。但資料夾、repo 名、網址、`localStorage` 的 `rubble.` 前綴、`config.js` 的 `NET.PREFIX` 都維持 rubble，改了會讓舊連結和玩家存的設定失效。

### 加同步功能時要守的模型

- 房主端的 `authority.js` 是裁判：回合、血量、分數、錢、選卡都在那裡算。訪客只送請求。
- 命中、技能、火焰傷害是「出手的人說了算」，自己這邊先生效再通知對方。這是刻意的取捨（朋友對打，不防作弊），不要當成漏洞去修。
- 會改地形或跨回合的訊息都要帶局數，收到的那一邊要檢查局數和每個數字欄位（參考 `main.js` 的 `_cleanExpl`、`skills.js` 的 `onNet`）。
- 練習機器人是假裝成訪客、走同一套訊息的。加了新訊息，`bot.js` 也要處理，不然單人練習會壞。

### 測試的坑

- 測試裡每位玩家要各開一個視窗（`Target.createTarget` 的 `newWindow`）。放在背景分頁的那一個不會跑畫面。
- 同一個瀏覽器的兩個視窗共用 `localStorage`，測雙人時設定會互相蓋掉。
- 開機要先算材質，不能等固定秒數。一律用 `tests/load.mjs` 的 `load()`，它會等到 `window.__game` 出現。
- `python -m http.server` 同時被好幾套測試打的時候會斷線。一次跑一套，或另外開一個埠用 `BASE` 指過去。
- 把玩家直接傳送進牆裡，會被脫困機制頂到別的地方。測試要自己蓋一塊空地再擺人（參考 `tests/rogue.mjs`）。
- 手動試：網址加 `?local=1` 可以同一台電腦開兩個視窗對打，`?nolock=1` 不鎖滑鼠，主控台的 `__game` 可以直接操作遊戲。
- 看畫面：`GPU=1 node shot.mjs <檔名> high "<要執行的 JS>"` 截選單或固定鏡位，`node shot-play.mjs` 進練習場連拍。截圖放在 `tests/shots/`，不進版本控制。
