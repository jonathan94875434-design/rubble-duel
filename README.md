# tay is gay

瀏覽器裡的雙人單挑 FPS：地形可以打爛、每局重置、用錢買裝備、輸家有補償、搶分制。
另外有兩個打機器人的模式：一個人練槍的「死鬥練習」，和兩個人合作的「守據點」。
純靜態網頁（Three.js + PeerJS），沒有建置步驟，也不需要自己的伺服器。圖片、模型、音效全部由程式產生，沒有任何素材檔。

線上版：https://jonathan94875434-design.github.io/rubble-duel/

> 要改這個專案的人（和他的 Claude）：先看最後一節「[交接](#交接給協作者和他的-claude)」。

## 怎麼玩

- 跟朋友玩：一人按「建立房間」→「複製邀請連結」傳給對方，對方打開後按「加入房間」。等朋友的時候可以按「熱身」先跟機器人打（無限重生），朋友一進來會自動回到大廳。
- 主選單分成四張卡片：跟朋友對戰、一對一練習、死鬥練習、守據點，各自的選項就在卡片上。
- 自己練：「一對一練習」卡片可以選對手難度（木樁／簡單／普通／困難）、地圖，也可以勾選用 Roguelike 模式。
- 打一大群機器人：主選單的「死鬥練習」「守據點」卡片（自己玩）；跟朋友一起玩就在房間裡點「守據點」或「機器人死鬥」。
- 視野 FOV 也跟 Apex 同一套數字（4:3 畫面的水平視角，70–110，預設 90；Apex 90 = 16:9 螢幕水平 106°）。舊版存的視野會自動換算，看到的範圍不變。
- 滑鼠靈敏度跟 Apex 同一套數字（滑鼠每動一個單位轉 0.022° × 靈敏度），在 Apex 用多少就填多少；開鏡倍率 1.0 也跟 Apex 預設一樣（照放大倍數等比變慢）。預設開「原始輸入」，不吃 Windows 的滑鼠加速（Mac 的瀏覽器不支援，會自動用一般模式）。舊版存的靈敏度會自動換算，手感不變。
- 補給箱：主選單左下的「補給箱」。打完一場拿抽獎券，開箱抽刀型和特殊塗裝（見下面「補給箱」）。
- 自己蓋地圖：主選單的「地圖編輯器」。存檔後會出現在地圖選單；「複製分享代碼」可以把地圖貼給朋友，對戰時房主選自製地圖也會自動傳給對方。
- 本機開發：Mac 雙擊 `start.command`、Windows 雙擊 `start.bat`，瀏覽器會打開 `http://localhost:8765/`。同一台電腦測雙人：網址加 `?local=1`，開兩個視窗。

## 規則

- **回合**：一局一條命，先拿到目標分數的人贏。每局地形重置。
- **經濟**：開場 $800，每局開打前買裝備（買了就花掉，商店每局重置）。第 1 局是手槍局。贏一局 +$2000，輸一局 +$3000，連敗每局再 +$500（上限 $4500）。
- **強化**：輸的人下一局可以三選一拿一個強化（房主可以在大廳改成不給）。
- **地圖**：廢墟廣場（黃昏）、三線街區（正午，有地下道）、貨櫃碼頭（陰天）、礦場（清晨，高地／谷底／隧道）、**城堡要塞（大地圖 72×72 公尺：中央兩層城堡可以上屋頂、四座三層高的哨塔、城外一圈小房子）**、**雙塔河谷（64×64 公尺：中間一條乾河道只有兩座橋能過，每邊兩座側塔、一座主塔）**、**沙城兩路（64×64 公尺：只有兩條路，A 長街和有屋頂的 B 地道，北邊兩個點位）**，加上自己做的。房主可指定、隨機或每局輪換。
- **身法**：急停、蹲跳、連跳；空中按方向鍵或轉視角就能轉彎，速度不會掉。跑步有腳步聲，瞄準走和蹲走沒有。拿刀跑最快。
- **穿牆**：子彈每穿過一格方塊會消耗穿透力（木板、鐵皮很薄；磚、水泥要步槍以上；鋼板幾乎只有狙擊槍穿得過一格），穿過去之後傷害打折。
- **護甲**：受傷先扣護甲，護甲扣光了才扣血（防彈衣、護甲片、軍火庫的護甲可以疊加）。
- **刀**：每個人都有，砍到就一刀斃命（護甲、減傷都擋不住，只有不死鳥救得回來）。左鍵快砍，瞄準鍵突刺（搆得比較遠、收刀慢）。
- **受傷方向**：被槍或刀打中時，準星外圍會有一段紅色弧線指向對手，轉頭時跟著轉。
- **投擲物**（2026-11-25 範圍大幅加大）：手榴彈半徑 7 公尺、炸開一大片方塊；煙霧彈的煙 5.5 公尺、維持 16 秒；燃燒瓶燒 4.2 公尺、9 秒，站在裡面一直扣血，會燒掉木頭；煙霧彈可以滅火。四種投擲物都**不限數量**，錢夠就一直買（點一下多一個，卡片上的「−」或右鍵少一個）；熱身和機器人模式免費，一種最多拿 5 顆。
- **小地圖**：對手只有在你看得到他、或他開槍時才會出現。
- **回合結束**：顯示傷害報告（雙方各打中幾發、打了多少傷害，打掉的護甲也算）；被擊倒的人會看到擊殺回放（點一下跳過）。

## Roguelike 模式

房主在房間裡點「Roguelike」卡片（一對一練習在卡片上勾「用 Roguelike 模式」）。

- **每局選一張異能卡**：開打前雙方各從 3 張裡選 1 張，整場累積。上一局輸的人有 4 張可以選，也比較容易抽到稀有、傳說、神話（取代一般模式的輸家強化）。
- **翻牌**：選卡時整個畫面暗下來，卡片背面朝上飛進來再一張一張翻開。顏色就是稀有度：**灰＝普通、藍＝稀有、金＝傳說、紅紫＝神話**，背面的光就已經是那個顏色，越稀有翻開時爆出的光越大。還沒翻開就點，會直接全部翻開（不會盲選）。
- **被動**不限數量，拿了就一直有效；**主動技能**最多帶兩個，按技能鍵施放。兩格都滿了再拿新技能，要挑一個換掉。
- **先選卡、再買裝備**：自己選好之前看不到對手這一局拿了什麼；選完才公開，接著才買槍。對戰中記分板下面也看得到對手帶的所有異能。
- **重抽**：花 $400 換一批，每局最多 2 次。
- **主動技能**：瞬移、鉤索、噴射背包、衝刺、鋼牆、腎上腺素、透視脈衝（普通）；光學迷彩、能量護罩、震地衝擊波、升天、賭博、梁允猴（稀有）；時間凝結、軌道砲（光柱會追人）、黑洞、換位（換完對手會背對你、暈 2 秒）、回溯錨點（按一次放錨點、再按一次回去；錨點還在時被打死會被救回錨點）（傳說）；**時間暫停、流星雨、堡壘、gay tay（神話）**。堡壘會在原地蓋一座小城堡（城牆、四角塔樓、城門開在你面向的那一邊），你直接站上中間 6 公尺高的哨塔頂；頭上有天花板就蓋不了。
  - **升天**：把看得到的對手（50 公尺內）原地噴上 11 公尺高、扣 20 血。
  - **賭博**：擲硬幣，贏了對手、輸了自己，隨機吃一種負面效果（凝結、時間暫停、致盲、升天、著火）。
  - **召喚**：「梁允猴」是會自己找人撲上去抓的小猴子（60 血、14 秒）；「gay tay」是拿機槍的金色巨人，靠近會踩地把人震飛（700 血、20 秒）。召喚物頭上有名字和血條，對手可以開槍打掉。
- **被動**：原本的 12 個強化，加上鷹眼、穿甲彈、雷達、無聲步、月球靴、投資客、軍火庫、求生本能、急救包、煙幕大師、閃光大師（普通）；扳機狂熱、玻璃大砲、重裝巨人、狂戰士、荊棘、冰凍彈、燃燒彈、爆裂彈、跳彈、超頻、獵人印記、爆破專家、縱火狂（稀有）；雙重射擊、不死鳥、子彈時間（傳說）；**死神、天神下凡（神話）**。
- 互相剋的例子：迷彩怕雷達和透視脈衝；護罩擋子彈但擋不了爆炸和走進來的人；軌道砲、流星雨會追人，要靠瞬移／衝刺／鉤索甩掉；黑洞、時間凝結可以用瞬移／鉤索／噴射背包逃；不死鳥、急救包專剋一刀斃命和爆頭。

- 投擲物的四張卡（煙幕大師、閃光大師、爆破專家、縱火狂）各自讓那種投擲物更大、更久或更痛，每局還多送一顆。

## 補給箱（局外抽獎）

主選單左下的「補給箱」。純外觀、不影響數值，對手看得到你的刀和塗裝。

- **抽獎券**：打完一場對戰 +2、一對一練習 +1、死鬥練習／守據點 +1，贏了再 +1。第一次玩送 3 張。開一次箱花 1 張。
- **開箱**：一長條物品從右往左滑、慢慢停下，中間金線停在哪一格就是抽到的（其實按下去就決定了，轉盤只是表演）。轉的時候點一下可以直接看結果。
- **機率**：精良 52%、稀有 27%、隱秘 12%、神話 5%、傳奇刀 4%。連續 20 抽沒出刀，下一抽一定出刀。抽到已經有的東西變成碎片，3 片自動換 1 張券。
- **刀型**（傳奇刀）：蝴蝶刀、爪刀、獵刀。換的只是模型，刀的數值都一樣。
- **特殊塗裝**：每一個都只能用在指定的那把武器上，例如「赤焰龍」狙擊槍（原創的紅金色東方龍，盤在槍托上、火沿著護木噴到槍口）、「星河」步槍、「霓彩漸層」刀（任何刀型都能用）。花紋全部是程式畫的（`js/finishes.js`）。
- **裝備**：補給箱的收藏、或造型頁的「刀與特殊塗裝」，點一下裝上、再點一下卸下。特殊塗裝優先於一般塗裝；沒有特殊塗裝的槍照樣用一般塗裝。
- 抽獎券、收藏、保底都存在這台電腦的瀏覽器裡（`localStorage` 的 `rubble.tickets`、`rubble.inv` 等），換電腦或清瀏覽器資料就沒了。

## 死鬥練習與守據點

這兩個模式都是無限重生、裝備全部免費（按商店鍵 B 換），對手換成一大群機器人。

- **死鬥練習**：場上同時有 4～16 個機器人，打倒會再補。可以選它們**定點不動、定點左右閃、主動來找你**或混合，也可以設成**不開槍**當靶子。時間 2／5／10 分鐘或不限，結算時記下這台電腦的最佳紀錄。
- **守據點**：地圖中間有一個發光的據點，機器人一波一波從地圖邊緣殺過來，據點被打爆就結束，看能撐幾波。
  - 每一波之前會在小地圖上用紅色箭頭預告敵人從哪幾個方向來。
  - 每一波之間休息 22 秒：**選一張強化卡**（Roguelike 的被動卡裡對機器人有用的那些）、換裝備、**用技能鍵 E 蓋沙包牆**（每次休息 3 道，機器人打得爛）。據點也會回一點血。
  - 好槍要撐到後面才開放：衝鋒槍第 1 波、霰彈槍第 2 波、步槍和射手步槍第 3 波、狙擊槍和輕機槍第 5 波，榴彈槍、火箭筒更後面。
  - 敵人：步兵、突擊兵（貼臉衝）、狙擊手（站遠）、重裝兵（血厚）、自爆兵（不開槍，衝到據點或人旁邊炸開，會閃白光；被沙包牆擋住就在牆邊炸出一個洞）、每 5 波一隻巨人（體型大、血條、會先畫紅圈再砲擊）。
  - 兩個人一起守時敵人多一半；朋友不用等，晚點進來也會直接加入，中途離開另一個人可以繼續守。
- 兩個模式都是同一隊：打不到隊友，閃光彈和爆炸對機器人也有效。

## 架構

- `main.js` 主迴圈、輸入、畫面狀態機
- `world.js` 體素世界（破壞、區塊網格、射線、穿牆、碰撞）；`maps.js` 內建地圖與自製地圖的編碼／解碼；`editor.js` 地圖編輯器
- `player.js` 移動物理（固定 120Hz）；`combat.js` 開槍、刀、後座、拋射物、火焰
- `net.js` 連線（WebRTC／同機／電腦對手三種通道）；`voice.js` 語音（PeerJS 通話，點對點）
- `authority.js` 裁判，只在房主端執行：血量、回合、分數、金錢、強化、補給品、地圖輪換、熱身的重生
- `cards.js` Roguelike 的卡片表與抽卡；`skills.js` 主動技能（施放、冷卻、對雙方的效果、特效）；`pets.js` 召喚物（梁允猴、gay tay：施放的人模擬，位置用 `sk` 訊息傳給對手）
- `crate.js` 補給箱（抽獎券、開箱、收藏）；`finishes.js` 特殊塗裝的花紋
- `bot.js` 一對一的練習對手；`nav.js` A* 尋路（也算「從出生點走得到哪些地方」）
- `horde.js` 死鬥練習與守據點：一大群機器人的模擬（房主）、角色模型、據點、砲擊預告
- 畫面：`textures.js` 方塊材質、`light.js` 天光（室內變暗）、`env.js` 天空與天氣、`post.js` 光暈與調色、`skylit.js` 讓角色和碎屑也吃到天光、`fx.js` 粒子／彈孔／爆炸／煙／火／噴漆
- 模型：`gunmodel.js` 槍與投擲物、`viewmodel.js` 第一人稱的槍和手、`remote.js` 角色（對手、造型預覽、擊殺回放裡的自己）、`icons.js` 把槍拍成商店用的小圖
- `hud.js` 介面；`minimap.js` 小地圖；`replay.js` 擊殺回放；`stats.js` 戰績；`audio.js` 合成音效
- 介面樣式全在 `css/style.css`，最上面的 `:root` 是設計基礎（字型、顏色、斜切角、警示帶）。字型從 Google Fonts 載入（中文 Noto Sans TC、數字 Saira Condensed、標誌 Saira Stencil One），連不上就用系統字型，遊戲照常運作；repo 裡沒有字型檔。
  HUD 在畫面高度 900px、1300px 以上會放大（`zoom`），準星不放大。小地圖的 canvas 本身要保留圓角和邊框（樣式表裡有註解說明原因）。
- `dev/` 是開發時看模型、聽音效用的預覽頁，遊戲本身不會用到

連線模型：房主管回合、血量與金錢；命中由開槍方判定（打到就算）；
方塊傷害與爆炸雙向同步，每局開始兩邊各自重建同一張地圖。火焰的傷害由丟的人負責算。
技能跟子彈一樣是「施放的人說了算」：自己這邊先生效，再用 `sk` 訊息告訴對手；會改地形的走既有的爆炸訊息。
選卡、重抽、金錢，以及荊棘／不死鳥／灼燒這類跟血量有關的被動，都在裁判那邊算。
機器人模式：機器人只在房主那邊模擬，每秒 15 次用 `mobs` 訊息把位置傳給訪客（開槍是 `mfire`、巨人砲擊預告是 `mwarn`）；
玩家打機器人一樣是開槍方判定，送 `mobhit` 給裁判扣血；機器人打玩家、打據點由房主判定。波次、據點血量、擊倒數在裁判的 `hz` 裡。

### 做事的規矩

- **push 到 `main` 大約 30 秒後就上線**（GitHub Pages），沒有測試環境，另一個人重新整理就會拿到。
  所以：動手前先 `git pull --rebase`；push 前跑跟改動有關的測試；一次提交一件事，訊息寫清楚改了什麼，因為另一個人是靠 `git log` 知道你做了什麼；不要 force push。
- **repo 是公開的。** 真名、信箱、金鑰都不要寫進檔案或 commit。commit 身分建議用 GitHub 提供的 noreply 信箱。
- **介面文字、註解、commit 訊息、這份 README 都用繁體中文。**
- **不要加框架、打包工具或素材檔。** 這是純靜態網頁，`vendor/` 裡只有 Three.js 和 PeerJS；圖片、模型、音效全部是程式產生的。要破例先問兩位玩家。
- **新功能要有測試**，加在 `tests/` 對應的那一套裡。改了規則或按鍵，README 上面幾節也要跟著改。
- **開放性的設計問題先問人**（新模式、大改玩法、要不要某個功能）。明確的要求（「把 X 改成 Y」）直接做。

### 已經定案的設計，不要改回去

這些都是原作者玩過之後指定的：

- 只做瀏覽器版，Mac 和 Windows 都要能玩。
- 不做炸彈模式。畫面走偏寫實。
- 左 Shift 也能瞄準，而且預設按鍵不能要求同時按滑鼠左右鍵，也不能只靠滾輪：Magic Mouse 做不到。

### 加同步功能時要守的模型

- 房主端的 `authority.js` 是裁判：回合、血量、分數、錢、選卡都在那裡算。訪客只送請求。
- 命中、技能、火焰傷害是「出手的人說了算」，自己這邊先生效再通知對方。這是刻意的取捨（朋友對打，不防作弊），不要當成漏洞去修。
- 會改地形或跨回合的訊息都要帶局數，收到的那一邊要檢查局數和每個數字欄位（參考 `main.js` 的 `_cleanExpl`、`skills.js` 的 `onNet`）。
- 練習機器人是假裝成訪客、走同一套訊息的。加了新訊息，`bot.js` 也要處理，不然單人練習會壞。
- 新的武器或傷害來源，判定命中要用 `main.js` 的 `rayTarget`／`eachTarget`／`hitTarget`，不要直接打 `g.remote`：對戰時目標是對手，機器人模式時是機器人（而且打不到隊友）。

### 測試的坑

- 測試裡每位玩家要各開一個視窗（`Target.createTarget` 的 `newWindow`）。放在背景分頁的那一個不會跑畫面。
- 同一個瀏覽器的兩個視窗共用 `localStorage`，測雙人時設定會互相蓋掉。
- 開機要先算材質，不能等固定秒數。一律用 `tests/load.mjs` 的 `load()`，它會等到 `window.__game` 出現。
- `python -m http.server` 同時被好幾套測試打的時候會斷線。一次跑一套，或另外開一個埠用 `BASE` 指過去。
- 把玩家直接傳送進牆裡，會被脫困機制頂到別的地方。測試要自己蓋一塊空地再擺人（參考 `tests/rogue.mjs`）。
- 手動試：網址加 `?local=1` 可以同一台電腦開兩個視窗對打，`?nolock=1` 不鎖滑鼠，主控台的 `__game` 可以直接操作遊戲。
- 看畫面：`GPU=1 node shot.mjs <檔名> high "<要執行的 JS>"` 截選單或固定鏡位，`node shot-play.mjs` 進練習場連拍。截圖放在 `tests/shots/`，不進版本控制。
