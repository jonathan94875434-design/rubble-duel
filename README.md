# RUBBLE 1v1

瀏覽器裡的雙人單挑 FPS：地形可以打爛、每局重置、用錢買裝備、輸家有補償、搶分制。
純靜態網頁（Three.js + PeerJS），沒有建置步驟，也不需要自己的伺服器。

線上版：https://jonathan94875434-design.github.io/rubble-duel/

## 怎麼玩

- 跟朋友玩：一人按「建立房間」→「複製邀請連結」傳給對方，對方打開後按「加入房間」。
- 自己練：按「單人練習」，可以選對手難度（木樁／簡單／普通／困難）和地圖。
- 本機開發：雙擊 `start.command`，瀏覽器會打開 `http://localhost:8765/`。同一台電腦測雙人：網址加 `?local=1`，開兩個視窗。

預設按鍵（都可以在「設定 / 按鍵」裡改）：WASD 移動、空白鍵跳（按住連跳）、C 蹲下、左鍵開火、右鍵或左 Shift 瞄準、
R 換彈、1/2/Q/滾輪切槍、G 手榴彈、F 閃光彈、V 煙霧彈、Esc 設定。

## 規則

- **回合**：一局一條命，先拿到目標分數的人贏。每局地形重置。
- **經濟**：開場 $800，每局開打前買裝備（買了就花掉）。第 1 局是手槍局。贏一局 +$2000，輸一局 +$3000，連敗每局再 +$500（上限 $4500）。
- **強化**：輸的人下一局可以三選一拿一個強化（房主可以在大廳改成不給）。
- **地圖**：廢墟廣場、三線街區（有地下道）、貨櫃碼頭、礦場（高地／谷底／隧道）。房主可指定、隨機或每局輪換。
- **身法**：Source 式移動——急停、蹲跳、旋轉跳、連跳；跑步有腳步聲，瞄準走和蹲走沒有。

## 想調整時改哪裡

| 想改的東西 | 檔案 |
| --- | --- |
| 移動手感、回合時間、經濟數字 | `js/config.js` |
| 槍枝數值與價格、投擲物、裝備 | `js/weapons.js` |
| 輸家強化 | `js/buffs.js`（效果實作在 `authority.js`、`combat.js`） |
| 地圖、出生點、補給品 | `js/maps.js`（`rampZ`/`rampX` 蓋坡道，`boxSym`/`boxMir` 保證對稱） |
| 方塊種類與耐久 | `js/world.js` 的 `BLOCK` |
| 造型 | `js/skins.js` |
| 預設按鍵 | `js/binds.js` |
| 機器人難度 | `js/bot.js` 的 `BOT_LEVELS` |

## 架構

- `main.js` 主迴圈、輸入、畫面狀態機
- `world.js` 體素世界（破壞、區塊網格、射線、碰撞）；`maps.js` 地圖
- `player.js` 移動物理（固定 120Hz）；`combat.js` 開槍、後座、拋射物與投擲物；`remote.js` 對手模型與插值
- `net.js` 連線（WebRTC／同機／電腦對手三種通道）
- `authority.js` 裁判，只在房主端執行：血量、回合、分數、金錢、強化、補給品、地圖輪換
- `bot.js` 練習對手；`nav.js` 它用的 A* 尋路
- `hud.js` 介面；`fx.js` 特效與煙霧；`audio.js` 合成音效；`skins.js`、`gunmodel.js` 造型

連線模型：房主管回合、血量與金錢；命中由開槍方判定（打到就算）；
方塊傷害與爆炸雙向同步，每局開始兩邊各自重建同一張地圖。

## 測試

```
cd tests && npm install
npm run features    # 身法物理、尋路（四張圖）、經濟、投擲物、改鍵
npm run practice    # 每把槍、補給品、電腦對手流程
npm run duel        # 雙人完整流程（同機通道）
npm run duel:peer   # 同上，走真的 WebRTC
```
需要先啟動本機伺服器（`start.command`）。要測線上版：`BASE=https://… npm run duel:peer`。
